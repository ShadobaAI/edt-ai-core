# Поведенческие smoke-сценарии KORA

Это задачи выбора действий по bundled skills, а не тест совпадения слов в skills
и не модель реального EDT/OpenViking. Все факты задач синтетические.

1. Новый исполнитель без истории разработки читает только `kora-inputs.json`,
   текущие `skills/1c-routing/SKILL.md`, `skills/1c-code-index/SKILL.md`,
   `skills/1c-code-change/SKILL.md` и нужные references. Не показывать ему rubric.
2. Исполнитель отвечает по каждому ID: решение, необходимые следующие действия,
   существенные ограничения. Никаких изменений или внешних вызовов.
3. Отдельный reviewer сопоставляет ответы с `kora-rubric.json` и инструкциями.
   Оценивать смысл и реальные решения, а не совпадение формулировок.
4. При провале исправить инструкции/сценарий и повторить затронутые задачи новым
   исполнителем. Сохранить ответы и результат ревью в `kora*results.json`.

Сохранённый результат — один локальный качественный прогон текущих инструкций.
Он не гарантирует поведение другой модели/хоста и не заменяет независимый пилот,
live-приёмку источников, права, нормоконтроль или тесты настоящего изменения.
Runner Node не объявляет эти сценарии автоматическими CI-тестами.
