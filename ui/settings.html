    Сервисы проекта
    Подготовьте runtime и проверьте доступность MCP.
    

    

    Что проверяется
    Подготовка может скачать runtime и запустить code-index и BSL LS. Проверяются MCP-протокол, workspace API BSL LS и health индекса. Для EDT и v8std здесь проверяется только наличие URL. Полная готовность проекта проверяется отдельно.
