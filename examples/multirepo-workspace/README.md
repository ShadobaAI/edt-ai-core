# Пример профиля с несколькими репозиториями

В [профиле](.ai/project.yaml) перечислены шесть каталогов относительно общего
корня. Это макеты checkout без метаданных 1С и исполняемых тестов. Формат —
поддерживаемый `.ai/project.yaml`; отдельного формата workspace не требуется.

В реальном проекте разместите checkout внутри общего корня, проверьте пути,
назначьте каждому нужному репозиторию `edt_project` и настройте EDT endpoint
для этого профиля. Включайте YaXUnit, Vanessa и знания только после заполнения
их параметров. Профиль не содержит адресов и credentials.

Проверка примера из корня репозитория:

```sh
node scripts/profile.mjs validate examples/multirepo-workspace/.ai/project.yaml
```
