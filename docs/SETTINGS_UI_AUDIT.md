# Интерактивные элементы настроек

Перечень относится к `ui/settings.html`. Имена в таблице — ID элементов;
динамические элементы указаны отдельно. `tests/test-settings-ui.mjs` в
большинстве сценариев моделирует обмен с MCP;
сквозные сценарии связывают код формы и реальный MCP-процесс через
тестовую DOM-среду. `tests/test-settings-scopes.mjs` также обращается к
реальному MCP-процессу. Для предсказуемых путей в тесте выбора файла ответ
диалога подставляется отдельно; эти проверки не доказывают работу окон ОС.

| Элементы | Событие и ожидаемый результат | Условия и проверки |
| --- | --- | --- |
| `profileToggleButton`, `closeProfilesButton`, подложка | Открывают/закрывают список; Escape и Tab управляют фокусом на узком экране | Только общий вход; закрытие возвращает фокус; тесты адаптивной навигации |
| `historySearch`, карточка и кнопка удаления профиля | Поиск фильтрует историю; выбор доступной карточки загружает настройки; удаление убирает запись из списка и может открыть другой доступный профиль | Черновик блокирует переход; автоматический переход доступен при незакреплённом каталоге, без режима просмотра и ошибки выбора; файлы не удаляются |
| `addProfileButton`, `directoryChooser`, `projectRoot`, `pickDirectoryButton`, `selectProfileButton` | Открывают выбор каталога; Enter или кнопка выбирают введённый путь | Нативный диалог возвращает результат или отмену; черновик блокирует переключение; тесты отложенного результата и ошибок |
| `openDirectoryButton`, `refreshButton`, `resolveChatButton` | Открывают известную папку, обновляют сведения или запрашивают каталог чата | Папка открывается через Проводник на Windows; просмотр и ошибки выбора не меняют привязку |
| `createButton`, `repairButton` | Создают отсутствующий профиль или открывают исходный документ для исправления | Создание не заменяет существующий файл; исправление проходит preview/apply и подтверждение замены |
| `renameButton`, `projectIdInput`, `renameSaveButton`, `renameCancelButton` | Открывают ввод, сохраняют или отменяют изменение `project.id` | Проверяются схема и revision, создаётся backup; `profile_id` и путь не меняются; предупреждение о разрешениях Vanessa |
| `profileTab`, `checkTab`, `editorTab`, `importTab`, `supportTab` | Показывают раздел; стрелки, Home и End перемещают фокус между доступными вкладками | Импорт при отсутствующем/повреждённом профиле доступен рядом с созданием; экспорт находится в разделе переноса |
| `connectionScope`, `edtUrl`, `v8stdUrl`, `openvikingUrl`, `openvikingEnabled`, `openvikingTimeout`, `openvikingMaxResponseBytes`, `openvikingHeadersEnv` | Выбирают область рядом с кнопкой сохранения и редактируют её значения | Показаны назначение и файл области, источник поля и действующее значение; отсутствие значения означает показ действующего; черновик переносится при смене области и сохраняется в выбранную; окружение и внешний файл имеют приоритет |
| `saveButton`, `probeButton`, `useEdtPortButton`, `migrateConnectionsButton`, динамический сброс URL | Сохраняют изменения, отдельно проверяют адреса, применяют подсказку порта или возвращают наследование | Сохранение требует изменений и проверяет revision начала черновика; опрос не обновляет её, после собственной успешной записи остальные черновики переходят на подтверждённую revision; проба не записывает; сброс явно удаляет URL instance override и недоступен при черновике адреса |
| `componentScope`, `codeIndexEnabled`, `bslLsEnabled`, `saveComponentsButton` | Меняют и сохраняют включение компонентов | Выбор и сохранение рядом; допустимы локальные настройки и настройки экземпляра; источник и действующее состояние каждого компонента отображаются отдельно |
| `bslLsJava`, `javaScope`, `pickJavaButton`, `checkJavaButton`, `saveJavaButton` | Выбирают область и каталог, проверяют исполняемый файл и явно сохраняют путь | Выбор и сохранение области рядом; видны источник пути и действующее значение; выбор и проверка не записывают настройки; результат содержит путь/версию или ошибку; учитывается исходный профиль операции |
| `editorDocument`, `editorMode`, `settingsText`, дерево JSON, выбор типа в строке, `formatJsonButton` | Выбирают настройки экземпляра, локальные настройки проекта, профиль или общие настройки; меняют представление, содержимое, типы и форматирование | Профиль и общие настройки отображаются и записываются отдельно; смена документа не теряет черновик; строки без кавычек в дереве; невалидное значение не меняет документ и блокирует preview; текстовый JSON/YAML остаётся редактируемым |
| `editSettingsButton`, `loadButton`, `reviewEditButton` | Загружают документ, перечитывают профиль или проверяют изменения | Незавершённый документ не заменяется; revision и схема проверяются до записи |
| `importSource`, `sourceProfile`, `includeProfileConnections`, `file`, `pickImportFileButton`, `includeMachineSettings` | Выбирают источник и явно разрешают перенос подключений, машинных параметров и команд тестов | Доступен другой зарегистрированный профиль; локальные overrides не копируются; выбор файла отменяем, размер ограничен 2 МиБ |
| `previewButton`, `replace`, `applyButton` | Проверяют импорт/редактирование и сохраняют проверенную ревизию | Предупреждают о путях, замена требует флажка и создаёт backup; изменение исходных данных инвалидирует preview |
| `downloadButton`, `openExportButton`, `diagnosticsButton`, `openDiagnosticsButton` | Сохраняют настройки/диагностику или открывают папку сохранённого файла | В Windows путь выбирается в «Сохранить как», отмена не сообщает об успехе; в Linux и macOS используются отдельные файлы каталога состояния. Результат перечитывается; отчёт формируется без передачи в сеть |
| `updateComponent`, `versionButton`, `versionSearch`, варианты списка, `refreshVersionsButton`, `moreVersionsButton`, `installUpdateButton` | Выбирают, ищут и устанавливают выпуск | Клавиатурная навигация и отмена списка; установка требует разрешения и не повторяется при polling; поздний каталог не заменяет другой компонент |
| `readinessButton`, `indexRepository`, `rebuildIndexButton` | Проверяют готовность или пересоздают выбранный индекс | Разрешения привязаны к проекту/экземпляру; результат чужой операции не применяется к текущему профилю |
| `diagnosticsRefreshButton`, `logSearch`, `logLevel`, записи журнала | Обновляют, фильтруют и раскрывают журнал | Диагностика доступна во время операции; содержимое журнала выводится как текст |
| `discardDraftButton`, раскрываемые `details` | Отменяют черновик или показывают дополнительные сведения | При внешней смене проекта черновик сохраняется для просмотра, запись блокируется до отмены; `beforeunload` запрашивает защиту от закрытия, если хост её поддерживает |

Все основные действия проходят общий контроль занятости; длительные операции
отслеживаются по ID без автоматического повтора. Тесты охватывают готовность,
успех, ошибку, отмену, блокировку, изменение профиля и запоздалые ответы.

Нативные COM-объекты создания окон проверяются на Windows без показа. Реальные
передний план, владелец, возврат фокуса и поведение окна Codex требуют отдельной
интерактивной проверки; автоматические тесты с подставленным выбором их не
подтверждают.
